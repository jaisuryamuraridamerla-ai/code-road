# CodeRoad 🚀

**Every CSE roadmap in one place.** Step-by-step learning paths for DSA, Web Development, AI/ML, C, core CSE subjects, placements, GATE, cybersecurity, app development, DevOps and tech content writing, with free resources and a built-in progress tracker.

Made for students of **IITs, NITs, IIITs and every other college**.

🔗 **Live site:** https://jaisuryamuraridamerla-ai.github.io/coderoad/

## ✨ Features

- 13 roadmaps, each with its own full page
- Phase-wise topics with checkboxes (progress is saved in your browser)
- Video, course and practice links for every roadmap
- LeetCode problems grouped by DSA topic
- "Build my plan" generator by year and goal
- Year-by-year game plan and tips for every college tier
- Light and dark mode, search and category filters
- Works on phones, tablets and desktops

## 🗺 Roadmaps

C Programming · DSA & Problem Solving · Web Development · AI / Machine Learning · Core CSE Subjects · Placements & Jobs · Tech Content Writing · Dev Tools & Open Source · Competitive Programming · GATE & Higher Studies · Cybersecurity · App Development · DevOps & Cloud

## 🛠 Tech

A single `index.html` file with plain HTML, CSS and JavaScript. No build step and no dependencies.

## ▶ Run locally

1. Download or clone this repository.
2. Open `index.html` in any browser.

## 🌐 Deploy

Hosted with GitHub Pages: **Settings → Pages → Deploy from a branch → main / root**.
